### Description
A collection of starter Exercism exercises in Rust. Steps through dealing with strings, user input, numbers. There is also a few exercises involving loops and eventually near the end dealing with structs and implemntations with enums, Object-like.

### Build & Running

Build using `cargo build --release`, everything should be running fine I hope. :/ I might provide a powershell script to run all of the special cargo build tools, but for right now it has no error checking or anything, just for myself to stop having to type a lot.

You can probably see the evolution of me learning if you go through the order from string, prime, squares, brackets, and then the last few.
